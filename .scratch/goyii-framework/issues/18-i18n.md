## Comments

**落地形态**（main `15e62ba`，分支 feat/i18n 已 ff 合入并删除）：

- **MessageSource**（`i18n.NewMessageSource(fsys, opts...)`）：构造时急切加载 `<lang>/<category>.json`（不可变、并发读免锁）；FS 可传 messages 根目录 FS，也可把 `//go:embed messages` 的 embed.FS 直接传入（"messages/" 前缀透明剥掉，doc.go 记示例）；值 = 字符串或复数 forms 对象；坏文件/坏语言目录 slog.Warn 跳过不炸应用，缺目录 = 空源全回退。选项 `WithSourceLanguage` / `WithDefaultLanguage`（默认显示语言缺省取源语言 en-US）。
- **`i18n.T(ctx, category, msgID, params map[string]any)`**：消息 ID = 源语言串；`{name}` 占位替换（数字经 x/text 按语言本地化，1.234,5）；查不到回原文；ctx 无 source（CLI）时同样只做参数替换。
- **复数简化实现**（工单允许记 Comments）：JSON 值可以是 `{"one": "...", "other": "..."}`，整数 `params["n"]` 驱动 `x/text/feature/plural` 的 CLDR 基数规则选形（按条目所在语言的规则），非整数/缺参落 "other"；未接 x/text/feature 的模板内嵌复数语法。
- **语言回退链**：`i18n.AcceptLanguages(header)` 解析 q 值排序（x/text 整头失败时逐条降级解析）；`MessageSource.Negotiate(prefs...)` 用 x/text matcher 把偏好映射到已有翻译目录（zh-Hans-CN -> zh-CN、en-GB -> en-US、无亲和 -> 默认），返回目录键（不吃 matcher 的 -u-rg 装饰后缀）；单条目 miss 沿父链降级 zh-CN -> zh -> und，全 miss 回消息 ID。
- **Formatter**（`i18n.F(ctx)` / `NewFormatter(lang)`）：数字 `x/text/number`（en 1,234.5 / de 1.234,5）、货币 `x/text/currency`（符号 + 币种标准小数位：$ 1,234.50 / US$ / ￥ / € 1.234,50；未知 ISO 码原码前缀回退）；日期 Date/DateShort/DateLong/Time/DateTime。**API 分叉记录——日期不走 x/text**：x/text/date 包无公开 API（仅 gen/tables），改为六语言 Go layout 表（en/zh/ja/ko/de/fr，含本地化月份名词表 + 词边界替换防 "Jan" 蚀 "Januar"），无表语言经父链/Base 语言回退（zh-TW 命中 zh 简体模式）最终落英文。
- **web.Language() 中间件**（NewHandler 黀装，位于 session 之后）：`?lang=` 参数 > 会话（`web.LanguageSessionKey = "language"`）> Accept-Language > 应用默认（config.i18n.language，空则 App.Language 源语言）。**分叉记录——优先序与工单文字的差异**：工单写「Accept-Language/参数 -> 会话 -> 默认」；若头排在会话前，浏览器必发 Accept-Language，会话内切换会被头永久覆盖，与验收「会话内切换保持」直接矛盾——采用 参数 > 会话 > 头 > 默认（Yii2 官方语言协商指南同序：显式请求信号最高，会话其次，头兜底），参数驱动的切换写入会话粘住。无会话中间件的自定义链下中间件仍可单独工作。
- **验证消息翻译联动——分叉记录（接 09 号留的缝）**：不换全局 `conf.IssueFormatter`，改在 `validators.Validate` 的 Flatten 边界统一翻译（消息 ID=源串，查 app 类别，miss 回原文）。理由：① conf.IssueFormatter 是包级全局变量，并发请求不同语言互相踩，per-request 语言进不去；② zog 只在消息为空时调 formatter，`z.Message("...")` 显式消息（Yii2 心智的主用法）根本不经过它，全局替换恰好漏掉主路径；③ Flatten 后单点翻译对 zog 默认表与显式消息两来源一致。类别可换：`validators.MessageCategory`（默认 "app"，启动期设置）。
- **API 变更记录**：`validators.Validate(model, scenario)` -> `validators.Validate(ctx, model, scenario)`（ctx 惯例首参）。理由：翻译需要请求上下文；并行 ValidateCtx 双入口会形成「一条路径翻译一条不翻译」的陷阱；ar 保存链路与 `ar.Model.Validate` 内部传记录绑定 ctx，CLI/裸 ctx 自动降级为不翻译。09 号测试调用点同步更新。
- **base**：`Application.I18n()/SetI18n()`（component 持有器；默认 `os.DirFS(cfg.I18n.MessagesDir)` 构造）；`WithContext` 在 appKey 之外把 i18n source 注入 ctx（i18n 自己的 key——i18n 包不 import base，避免 base -> i18n -> base 环）。
- **config**：新增 `i18n` 段 `{language, messagesDir}`（默认 "messages"）；env 覆盖 `I18N_LANGUAGE` / `I18N_MESSAGESDIR` 由现有反射机制自动获得。
- **依赖**：`golang.org/x/text v0.41.0` 由 indirect 转 direct（无版本升级，go 指令 1.26.0 不动）；`go mod tidy` 顺带把实际被 view 直接 import 的 `github.com/a-h/templ` 归位 direct。

**验收证据**（合并后 main `15e62ba` 上，CGO 经 scoop mingw gcc 启用）：

- `go build ./...` / `go vet ./...` / `gofmt -l`（i18n/base/validators/web/db/config）全部无输出；`go test ./...` 全仓 17 包全绿。
- `CGO_ENABLED=1 go test -race -count=1 ./i18n/ ./validators/ ./web/ ./base/ ./db/ar/` 五包 ok、无 data race——含 `TestConcurrentTranslationAndLanguageSwitching`（32 goroutine × 200 次，6 种语言并发切换下 T + Negotiate + F 共享同一 source）。
- **按语言/类别加载 + embed 单二进制**（i18n 19 项）：`embed_test.go`（包外 `i18n_test`）以 `//go:embed testdata/messages` 把消息树编进测试二进制，`TestEmbeddedSourceTranslates` 直查三语言；`TestEmbeddedSourceServesTheRequestPipeline` 真实 base/web/validators 栈——默认请求回 en-US（msg "Hello, Ada!" + 价格 "$ 1,234.50"）、头 `zh-CN,zh;q=0.8` 得中文（"你好，Ada！" + "US$ 1,234.50"）、`?lang=de-DE` 得德文、422 验证消息按请求语言翻译（zh body 恰为 `{"name":["名称不能为空"]}`，默认请求回英文原文）；`messagesource_test.go` 覆盖 MapFS/embed 前缀双形态、坏文件/坏目录跳过、空源回退、选项默认值。
- **回退链 + 会话内切换保持**：`language_test.go` Negotiate 10 用例（exact / zh 精确命中 zh 目录 / zh-Hans-CN -> zh-CN / en-GB -> en-US / fr -> 默认 / 不可解析逐条跳过）；`translate_test.go` 父链两向（zh-CN 专属条目优先、miss 落 zh 父目录条目）；`web/language_test.go` `TestLanguageMiddlewareSessionStickiness`——`?lang=zh-CN` 发会话 cookie，后续无参请求 zh-CN 战胜 de-DE 头，再参数可再切；`TestLanguageMiddlewareWithoutSessionStillResolves` 无会话链仍解析且不落任何 cookie；embed e2e 的 sticky 断言同证。
- **Formatter 常用格式**（formatter_test.go 16 项）：Number en/zh/de 三语小数千分位；Currency 四币种 + 未知码回退；Date/DateShort/DateLong/Time/DateTime 八语言断言（en-GB 经父链命中 en、de "2. Jan. 2006" / "2. Januar 2006"、fr "2 janvier 2006"、ru 无表回退英文、zh-TW 经 Base 命中 zh、ko "2006년 1월 2일"）；`localizeMonths` 词边界用例防 "Jan" 蚀 "Januar"。
- **验证错误翻译后形态**：validators `i18n_test.go` 4 项（zh-CN 下 `map[name:[名称不能为空] email:[邮箱不是有效地址]]` 精确断言、未命中条目保持原文、无 source 的 nil ctx 与 Background 原文、无翻译语言回源串）；db/ar `TestSaveTranslatesValidationMessagesForRequestLanguage`——保存链路拒绝写入 + 消息中文翻译 + 字段->[]消息形态 + 库计数 0；validators 既有英文 422 e2e（web_test.go）不动仍绿。
