# 配置参考

配置归项目所有：结构体由项目定义、yaml 文件由项目决定、字段想加就加。框架只提供一个通用装载工具——`config.LoadAs[T](dir)` 把任意项目 struct 从 yaml + 环境变量填满——和各组件包的参数包（`cache.Config`、`db.Config`…）。值走 yaml / env，行为在 `main.go` 用代码装配。

## 加载流程

```mermaid
flowchart LR
    A["app.yaml<br/>（基础值；${VAR} 插值先展开）"] --> B["web-&lt;env&gt;.yaml overlay<br/>（同样支持插值；GOYII_ENV 选择，<br/>可缺省，只覆盖点名字段）"]
    B --> C["环境变量覆盖<br/>（字段路径大写下划线，<br/>空值视为未设置）"]
    C --> D["项目自定义 struct T<br/>（LoadAs 不填默认，<br/>零值原样通过）"]
    D --> E["main.go 构造组件<br/>（New 内部兜默认：<br/>零值 == 默认行为）"]
```

```go
import goyii "github.com/goyii2/framework/config"

cfg, err := goyii.LoadAs[config.Config]("config") // 项目自己的 config.Config
if err != nil { /* boot 失败 */ }
```

三台机器（对任意项目 struct 生效）：

1. **环境选择**：`GOYII_ENV`（非空即生效，默认 `dev`）；`goyii.Env()` 读出当前环境名。
2. **overlay**：`<dir>/app.yaml` 先载，`<dir>/web-<env>.yaml` 叠加其上——overlay 只覆盖它点名字段，其余保 app.yaml 值；overlay 文件不存在即跳过。app.yaml 与 overlay 至少存在一个，否则报错。
3. **env 覆盖**：叶子字段的路径（yaml 键）全大写下划线即变量名——`DB.DSN -> DB_DSN`、`App.Debug -> APP_DEBUG`、`Cache.Redis.Addr -> CACHE_REDIS_ADDR`、`Email.APIKey -> EMAIL_APIKEY`。空值视为未设置；类型支持 string / bool / 整数 / 浮点 / `time.Duration`（`90s` 这类写法）；值解析失败报错。**变量名派生自项目 struct 的字段路径**——项目把 `db.Config` 嵌在哪个 yaml 键下，前缀就是什么。

`LoadAs` 的目标 `T` 必须是 struct（其他形状报错）；装载器不填任何默认值：项目 struct 的零值原样到达组件构造器，默认值由各组件包的 `New` 内聚处理（零值 Config = 默认行为）。不使用 `LoadAs` 完全合法（自选 viper / koanf / flags），框架核心不依赖 config 包。

## 环境变量插值（compose 风格）

两个配置文件（app.yaml 与 overlay）在 yaml 解析**之前**先做 `${VAR}` 插值——进程环境变量直接拼进文件值里，语法与 docker compose 一致：

```yaml
db:
  dsn: "${DB_USER}:${DB_PASS:?db password is required}@tcp(db.internal:3306)/app"
mail:
  from: "${MAIL_FROM:-goyii <no-reply@example.com>}"
```

| 写法 | 变量未设置时 | 说明 |
|---|---|---|
| `${VAR}` / `$VAR` | 展开为空串 | 普通拼接 |
| `${VAR:-默认}` | 展开为 `默认` | 变量为空串时也取默认 |
| `${VAR-默认}` | 展开为 `默认` | 仅未设置时取默认（已设置的空串保留） |
| `${VAR:?消息}` / `${VAR?消息}` | **装载失败** | 强制必填：未设置**或为空串**都算缺失，错误信息含文件名、变量名与消息 |

与第 3 台机器（整字段 env 覆盖）的分工：插值作用于**文件值内部**（把变量拼进值里），env 覆盖作用于**整个字段**——同一字段两者都命中时，整字段覆盖最后生效（`DB_DSN` 压过文件里拼好的 DSN）。`$` 后跟非标识符字符（如 `$5`）保持字面；overlay 文件里的插值结果照常参与覆盖合并。

## 项目自定义 Config struct

写法定式（摘自 `examples/basic/config/config.go`）：身份字段项目自定义 + 组件参数包直接嵌入 + 全自定义段随意加：

```go
type Config struct {
	App struct {
		Name  string `yaml:"name"`
		Debug bool   `yaml:"debug"`
	} `yaml:"app"`

	Web struct {
		Listen string `yaml:"listen"`
	} `yaml:"web"`

	DB      db.Config      `yaml:"db"`
	Queue   queue.Config   `yaml:"queue"`
	Cache   cache.Config   `yaml:"cache"`
	Session session.Config `yaml:"session"`
	Mail    mail.Config    `yaml:"mail"`
	Log     log.Config     `yaml:"log"`

	I18n struct {
		Language string `yaml:"language"`
	} `yaml:"i18n"`

	// 项目自定义段：框架不认识这些字段，notifier 组件消费它们
	//（EmailConfig{APIKey, Sender} 是同文件里的普通 struct，带 yaml tag）
	Email EmailConfig `yaml:"email"`
}
```

- 嵌入哪个组件参数包、嵌在哪个 yaml 键下、要不要 i18n 段，全由项目决定——不需要的组件整段省掉即可。
- `log.Config` 里的 `Gorm` 子段随 log 段走（查询日志的展示侧值），装配时喂给 `app.ConnectDB(cfg.DB, cfg.Log.Gorm)`。
- 自定义段照常享受三台机器：`examples/basic` 的 `email.apiKey` 在 app.yaml 写基值，`web-dev.yaml` overlay 覆盖为 dev 键，`EMAIL_APIKEY` 环境变量压过两者——启动日志会打出 notifier 最终解析到的键，三层机器并排可见。

## 组件参数包总表

各表字段均为组件包 `Config` 的 yaml 键；「默认」指该字段为零值时构造器在 `New` 内部落到的值。环境变量名以 `examples/basic` 的嵌法（yaml 键 `db` / `cache` / …）为例——项目换嵌法，前缀随之变。

### cache — `cache.Config`

| 字段 | 默认 | 环境变量 | 说明 |
|---|---|---|---|
| `driver` | `memory` | `CACHE_DRIVER` | `memory` / `file` / `redis` |
| `keyPrefix` | `goyii:cache:` | `CACHE_KEYPREFIX` | file / redis 键命名空间 |
| `ttl` | `3600` | `CACHE_TTL` | 秒；调用传 `ttl <= 0` 时的默认寿命 |
| `path` | 系统临时目录 `goyii-cache` | `CACHE_PATH` | file 后端目录 |
| `redis.addr` / `redis.password` / `redis.db` | 空（go-redis 自身默认） | `CACHE_REDIS_ADDR` 等 | redis 驱动**未注入** WithRedis 时的专用连接值 |

redis 驱动的正源是装配时 `cache.New(cfg.Cache, cache.WithRedis(client))` 注入应用共享连接，此时 `redis:` 子段被忽略。

### mutex — `mutex.Config`

| 字段 | 默认 | 环境变量 | 说明 |
|---|---|---|---|
| `driver` | `process` | `MUTEX_DRIVER` | `process`（进程内）/ `redis`（跨进程） |

redis 驱动**没有连接值字段**——互斥锁天生跨进程协调，必须注入共享连接：`mutex.New(cfg.Mutex, mutex.WithRedis(client))`；缺连接在构造期报错。

### queue — `queue.Config`

| 字段 | 默认 | 环境变量 | 说明 |
|---|---|---|---|
| `driver` | `sync` | `QUEUE_DRIVER` | `sync`（即推即执行）/ `db`（建表存消息）/ `redis` |
| `tableName` | `queue` | `QUEUE_TABLENAME` | db 驱动队列表名（`queue.NewMigration` 建表） |
| `pollIntervalMs` | `1000` | `QUEUE_POLLINTERVALMS` | listen 空闲轮询间隔（测试可调短） |

db / redis 驱动共用应用级连接（专用连接会发出别的进程看不到的消息），故无连接子段：装配时 `queue.New(cfg.Queue, queue.WithDB(app.DB()), app.QueueDispatcher())` 或 `queue.WithRedis(client)`；缺依赖在构造期报错。

### db — `db.Config`

| 字段 | 默认 | 环境变量 | 说明 |
|---|---|---|---|
| `driver` | `mysql` | `DB_DRIVER` | `sqlite` / `mysql` / `postgres` / `sqlserver`（别名 sqlite3 / postgresql / mssql） |
| `dsn` | 无（必填） | `DB_DSN` | 驱动各自格式；`DB_DSN` 覆盖在 `db.New` 内生效（不走 LoadAs 也有效） |

db 无兜底组件：装配 `app.ConnectDB(cfg.DB, cfg.Log.Gorm)` 失败即 boot 失败；未装配即访问 `app.DB()` panic。

### session — `session.Config`

| 字段 | 默认 | 环境变量 | 说明 |
|---|---|---|---|
| `name` | `goyii-session` | `SESSION_NAME` | 会话 cookie 名 |
| `backend` | `file` | `SESSION_BACKEND` | `file` / `redis` |
| `path` | 系统临时目录 `goyii-session` | `SESSION_PATH` | file 后端目录 |
| `timeout` | `1440` | `SESSION_TIMEOUT` | 秒（24 分钟） |

redis 后端注入共享连接：`session.New(cfg.Session, session.WithRedis(client))`；缺 client 在构造期报错。cookie 属性（HttpOnly / SameSite 已有防御默认）在返回的 Manager 上调整。

### mail — `mail.Config`

| 字段 | 默认 | 环境变量 | 说明 |
|---|---|---|---|
| `driver` | `log` | `MAIL_DRIVER` | `log`（记录到日志）/ `smtp` |
| `from` | 无 | `MAIL_FROM` | 缺省发件人（`Name <addr>` 或裸地址） |
| `smtp.host` | 无（smtp 必填） | `MAIL_SMTP_HOST` | |
| `smtp.port` | `587`（smtps 时 `465`） | `MAIL_SMTP_PORT` | |
| `smtp.username` / `smtp.password` | 空 | `MAIL_SMTP_USERNAME` 等 | username 空则不做认证 |
| `smtp.encryption` | `starttls` | `MAIL_SMTP_ENCRYPTION` | `none` / `starttls` / `smtps`（别名 tls / ssl） |

### log — `log.Config`

| 字段 | 默认 | 环境变量 | 说明 |
|---|---|---|---|
| `level` | `info` | `LOG_LEVEL` | 根级别：`debug` / `info` / `warn` / `error` |
| `targets[]` | 单 console target（stdout） | —（切片不参与 env 覆盖） | 多 target 依次登记 |
| `gorm.disable` | `false` | `LOG_GORM_DISABLE` | 关掉 GORM 查询日志适配器 |
| `gorm.slowThresholdMs` | `0`（关闭慢查询检测） | `LOG_GORM_SLOWTHRESHOLDMS` | 慢查询阈值（毫秒，达阈值记 WARN） |

`log.targets[]` 每个 target：

| 字段 | 说明 |
|---|---|
| `type` | `console` / `file`（空 = console） |
| `minLevel` | 该 target 的级别下限（空 = 不设自己的门槛） |
| `categories` | 类别包含模式（`db`、`db*`、`*`；空 = 全部） |
| `except` | 类别排除模式，优先于 categories |
| `path` | file：日志文件路径 |
| `maxSizeMB` | file：超此大小轮转（默认 10） |
| `maxFiles` | file：保留的轮转份数（默认 5） |

### i18n — 项目自持段

i18n 无参数包（无值组件，直接构造）：消息树在代码里 embed，显示语言经构造选项注入——`i18n.NewMessageSource(messages, i18n.WithDefaultLanguage(cfg.I18n.Language))`。语言字段叫什么、放哪个段，项目自定。
