# Triage 标签

各技能以五个标准 triage 角色沟通。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库的标签         | 含义                        |
| -------------------------- | -------------------- | --------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估该工单        |
| `needs-info`               | `needs-info`         | 等待提交者补充信息          |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，可交给 AFK agent  |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现                |
| `wontfix`                  | `wontfix`            | 不予处理                    |

当技能提到某个角色（如「打上 AFK 就绪的 triage 标签」）时，使用表中「本仓库的标签」列对应的字符串。

如需改用既有词汇，直接编辑「本仓库的标签」列即可。
